# Jean Cacheux website — rebuilt from scratch

Upload every file in this folder to the root of `jeancacheux.github.io`.

The carousel is driven by JavaScript rather than CSS animation. It:
- starts automatically;
- loops infinitely;
- pauses on hover or touch;
- can be dragged or swiped manually.

The public URL remains exactly:
https://jeancacheux.github.io/

No `?v=3` is required. That suffix was only a temporary cache-busting trick.
